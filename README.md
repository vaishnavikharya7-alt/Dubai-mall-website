# Dubai Mall Interactive Sales Deck

A cinematic, browser-based luxury sales experience built to reimagine how mega destination properties pitch themselves to retail tenants, sponsors, and event partners.

Inspired by Apple-style storytelling, Tesla-level minimalism, luxury fashion aesthetics, and immersive destination marketing, this project transforms traditional static presentations into an interactive digital experience.

---

## 🌐 Live Demo

https://dubai-mall-website.vercel.app

---

## 📌 Overview

This project showcases an interactive sales platform centered around The Dubai Mall — one of the world’s largest and most iconic shopping and entertainment destinations.

The experience is designed for:
- Retail leasing opportunities
- Sponsorship partnerships
- Event bookings
- Brand activations
- Luxury retail positioning

Instead of static PDFs or disconnected sales materials, this platform creates a self-guided immersive experience that communicates the scale, energy, and commercial potential of the property within seconds.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/your-username/dubai-mall-sales-deck.git
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
